# Dataset note

`traffic_data.csv` is **synthetic data generated by `generate_dataset.py`** (seeded, reproducible).

> This dataset is used for academic demonstration and model development.

It is **not** real-time traffic, and it is **not** measured field data. It encodes plausible
patterns (peak hours, weekend relief, rain, road type) so the ML pipeline can be demonstrated
end to end. Real production traffic prediction would require a much larger real-world dataset
(GPS probe data, sensors, or a live traffic feed).

Columns: `hour, day_of_week (0=Mon), weekend, distance (km), weather, rain, route_type,
historical_traffic_level (0-2 noisy corridor average), traffic_level (target: LOW/MEDIUM/HIGH)`.
